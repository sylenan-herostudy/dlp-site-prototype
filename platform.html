Три опоры платформы

Единая, открытая, масштабируемая

Data Sulus проектируется как один связный слой, а не набор инструментов. Стек — открытый, без vendor lock-in. Архитектура — multi-tenant с первого дня.

Единая

Один слой от источника до инсайта: Ingestion собирает данные, Lakehouse чистит и версионирует, AI-BI отвечает на вопросы. Между слоями нет ручной склейки и экспорта-импорта между системами.

Открытая

Фундамент на open-source: Airbyte для коннекторов, Apache Iceberg для хранения, PostgreSQL для агрегатов. Никакого vendor lock-in — данные остаются в вашем S3 в открытых форматах. Глубокий AI-слой — наш собственный код поверх открытого стека.

Масштабируемая

Per-tenant шардинг данных, изоляция и multi-region. Каждый клиент — отдельный тенант со своими источниками, витринами и ключами шифрования. Платформа рассчитана на рост от первого пилота до десятков тенантов.

Архитектура

Три слоя, один поток данных

Данные поднимаются снизу вверх: сырые источники, очистка и витрины, ответы на вопросы естественным языком.

Сбор из 350+ источников

// слой 02
Storage

Lakehouse: bronze → silver → gold

Apache Iceberg плюс S3 для данных и PostgreSQL для агрегатов. Три уровня качества: bronze — сырые данные как есть, silver — очищенные и согласованные, gold — готовые витрины для дашбордов и API. Полная история версий данных: можно вернуться к любому состоянию и понять, откуда взялась каждая цифра.

// слой 03
AI-BI

AI-BI: промт → дашборд

LLM Router балансирует запросы между Claude Sonnet 4.6, Opus 4.7 и локальным Ollama qwen — по типу запроса, стоимости и приватному режиму. Вы спрашиваете естественным языком, например «маржа по SKU за квартал», и получаете график. On-prem Ollama обслуживает тенантов, которым нельзя отдавать данные третьим сторонам.

Lakehouse: bronze → silver → gold

Apache Iceberg + S3 + PostgreSQL. Полная история версий данных и три уровня качества — от сырых данных до готовых к анализу витрин.

  • bronze — сырые данные как есть
  • silver — очищенные и согласованные
  • gold — готовые витрины для дашбордов

Zero Cross-Tenant: данные изолированы

Каждый клиент — изолированный тенант. Per-tenant Fernet-шифрование, row-level security, отдельные RAG-коллекции. Даже разработчики Data Sulus не видят ваши данные.

  • Per-tenant ключи шифрования токенов
  • Row-level security во всех таблицах
  • Аудит-лог каждой операции

Документация Data API

Data API отдаёт готовые витрины gold-слоя в ваши приложения — Vox AI, Trendora, Hero и внешние сервисы. Каждый запрос привязан к тенанту, изоляция данных гарантируется на уровне строк.

  • Запросы к метрикам продаж, заказов и маржи по периодам
  • Токен тенанта в заголовке — никакого cross-tenant-доступа
  • Management API для тенантов, источников и аудита отдельно
  • SDK и примеры под основные языки и IDE-интеграции
Полный справочник Data API 
// получить метрики продаж тенанта
GET /v1/metrics/sales?period="quarter"
Authorization: Bearer "<tenant_token>"

// ответ
{ "revenue": 12400000, "orders": 3280 }

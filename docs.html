Data API
Data API

Reference: endpoints для чтения и стриминга

Всё, что нужно клиентскому приложению — от единичного запроса до WebSocket-стримов с инкрементами по факту.

POST /v2/query

Промт на естественном языке возвращает таблицу, чарт или JSON. Поддерживает SQL-fallback и context-window до 200k токенов.

Параметры запроса

GET /v2/datasets

Каталог bronze/silver/gold таблиц с метаданными Iceberg: схема, partitioning, last_snapshot, владелец, теги.

Структура ответа

WSS /v2/streams

WebSocket-стрим инкрементов. Подписываемся на dataset_id, получаем CDC-события за сотни миллисекунд после фиксации.

Протокол сообщений

POST /v2/export

Выгрузка в Parquet, CSV, Google Sheets или прямой push в клиентский Iceberg-warehouse через S3 sign-url.

Management API

Администрирование платформы

Управление тенантами, источниками, ключами и audit-логом. Изолировано от Data API, под отдельной аутентификацией.

Tenants CRUD

Создание, заморозка, удаление тенантов. Генерация пары Fernet-ключей, ротация без downtime, billing-метаданные.

/v2/admin/tenants

Sources & Connectors

Каталог 350+ коннекторов Airbyte плюс кастом-парсеры (таможня Китая, TikTok, ЦБ). Расписание, healthcheck, retry-политика.

/v2/admin/sources

Audit log

Immutable-журнал всех операций чтения и изменения. Экспорт в SIEM (Splunk, ELK), фильтры по tenant, user, dataset.

/v2/admin/audit
SDK & инструменты

Клиентские библиотеки и CLI

Официальные SDK покрывают Data API и Management API, поддерживают async, retry с экспоненциальным backoff и встроенный rate-limiter.

Архитектура

Три слоя «Data Sulus»

Ingestion на Airbyte и кастом-парсерах, Lakehouse на Apache Iceberg плюс S3, AI-BI с LLM Router. Каждый слой документирован отдельно с ADR-историей.

Ingestion слой

350+ коннекторов Airbyte, AI Data Engineer для автогенерации pipeline, batch и CDC-режимы. Bronze-слой — сырая копия источника.

Lakehouse

Apache Iceberg на S3 с time-travel и schema evolution, PostgreSQL для агрегатов. Silver-слой — очищенные данные, gold — витрины.

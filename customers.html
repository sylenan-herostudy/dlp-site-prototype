Потребитель Data API и балансировка LLM Router

VOX AI — AI-ассистент для CEO — обращается к Datasulus через Data API: чат-запрос превращается в обращение к gold-витринам и возвращается готовым дашбордом. LLM Router Datasulus балансирует эти запросы между Claude Sonnet 4.6, Opus 4.7 и локальным Ollama qwen с cost-cap на токены.

  • Запросы к gold-витринам через Data API, scoped по тенанту
  • Балансировка LLM Router: Sonnet 4.6 / Opus 4.7 / Ollama qwen
  • Cost-cap на токены и аудит обращений к API
«Чат с пользователем уходит в Data API Datasulus и возвращается живым дашбордом за секунды. LLM Router снимает с нас балансировку провайдеров и контроль стоимости.»
